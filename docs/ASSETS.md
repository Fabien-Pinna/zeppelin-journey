# Rebuild asset provenance

The visual brief is the user's `1.png`, `2.png`, and `3.png`: detailed warm floating dioramas, cream/teal/brass travel craft, floral planting, wood and stone, atmospheric cloud depth. These are perspective concept alternatives, not orthographic reconstruction sheets.

- `public/models/world-v2/{chapter}.glb`: nine original Blender-authored dioramas generated by `assets/blender/craft.py` and `islands.py`. Material-batched meshes, packed procedural textures, Draco compression. Each island has a real furnished environment, flowers/trees, lanterns and boarding pier.
- `traveller.glb`: original smooth profile character authored by `characters.py` using `organic.py`: tailored clothes, stitched seams, hands, sculpted face, swept hair, boots, backpack and packed fabric/leather normal maps. The supplied Ready Player Me file is inspiration only. Articulated object joints drive procedural motion, not motion capture.
- `acrobat.glb`: a second original character costume without the travel backpack, used by the trapeze artist and juggler. Named joints are normalized after Three.js sanitizes Blender numeric suffixes.
- `layouts.json` in `src/features/journey`: semantic collider dimensions exported with each diorama; moving glTF pivots use `ANIM-*` names. Lanterns, workstations, ladder and trapeze crossbeam were repaired in the source geometry.
- `zeppelin.glb`: adapted from the user's `C:/Users/Fabio/projects/zeppelin_factory/zeppelin_steampunk/zeppelin_steampunk.glb`. Removed cannon barrels, gunports, bowsprit and figurehead; replaced materials with the shared palette; added a glazed observation cabin, steps and luggage; teal tail surfaces. The source factory file was not overwritten.
- `public/textures/cloud-sea.png`: AI-generated distant environment only. Brief: a wide 2:1 softly painted dimensional cloud sea, blue/golden sky, distant mountains, no objects or lettering. Original generation: `exec-cf130a88-499e-4854-891b-a6b8830ba3e0.png`.
- `cloud-sea-evening.png`: image-generation edit of that background. Brief: preserve cloud/horizon composition, introduce periwinkle/indigo blue hour, peach cloud edges and tiny stars; no objects, moon or lettering. Original: `exec-61e89c78-248e-4f5b-9cce-d8fb0cfd795d.png`.
- `public/draco`: decoder files copied from the installed Three.js package; served locally, without a runtime third-party decoder dependency.

Editable scene: `artifacts/blender/zeppelin-journey-v2.blend` (local, ignored because it includes source and working meshes). Scripts and runtime GLBs are tracked. The original default Blender scene is preserved in the saved file. To regenerate in Blender, create/select a working scene, import the factory source, add `assets/blender` to Python's module path, then call `islands.build_chapter` for each chapter, `travellers.airship()` and `travellers.character()` plus `travellers.character("acrobat", False)`. `craft.ROOT` selects the checkout.

The character, ship and environments have been visually inspected. This is a new playable art pass inspired by the references, not an assertion of exact image fidelity or user acceptance.
